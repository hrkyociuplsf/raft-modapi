## Overview

Raft ModAPI is the community mod framework for Raft, providing an in-game mod browser, version management, and a C# API that exposes game hooks for crafting, building, ocean, and survival systems.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Raft ModAPI** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **In-Game Browser** | Browse, install, and update mods from within the game itself |
| **Version Manager** | Keep mods compatible with the installed game version automatically |
| **C# API** | Expose hooks for items, crafting recipes, building blocks, and entities |
| **Conflict Detection** | Warns when two loaded mods target the same game method |
